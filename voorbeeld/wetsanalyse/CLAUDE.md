# Voorbeeld: wetsanalyse

Referentie-implementatie voor `werkwijze-v2-multi-service`. Nog niet uitgebouwd.

Gericht op multi-service architectuur: meerdere deploybare services, Next.js BFF,
LLM-orkestratie, async achtergrondtaken. Dit is het startpunt voor v2-projecten — zodra de
implementatie vordert, illustreert deze map hoe de werkwijze eruitziet op deze stack.

De methodologie zelf staat in [`../../werkwijze/`](../../werkwijze/).
